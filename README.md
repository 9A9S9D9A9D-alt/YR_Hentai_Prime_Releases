## 최종 변경사항 · 2026-11-07

- **촉수 이식체와 포획** — 사목의 나무에서 이식 씨앗을 배양합니다. 이식체의 촉수 공격, 원거리 백윤액 사격, 전기 충전, 도약, 응급 처치와 포획를 지원합니다. 스플릿 마우스 외피는 한 번 펼쳐진 뒤 붙잡은 형태를 유지합니다.
- **스플릿 마우스 말풍선** — 모드를 로드한 뒤 붙잡힌 폰에게 실제로 적용된 기본 몸체를 표시합니다. SA0 사용 시 해당 몸체 부품도 포함합니다. 장비·의상·머리는 표시하지 않습니다. 자동 방향은 앞모습이며, 몸체의 위치·배율·방향을 종족·제노타입·체형·성별별로 저장합니다.
- **안쪽 촉수와 백윤액 착취** — 양옆에서 감기고 아래에서 교차하는 촉수가 말풍선 안에서 움직입니다. 게임용 이미지는 256×256, 약 22.9KB입니다. 스플릿 마우스로 대상을 붙잡은 상태에서 백윤액 착취를 시작하면 액체가 차오르고, 게임 시간 1시간 후 백윤액 10개가 배출됩니다. 백윤액 난사와 원거리 사출에 짧고 묵직한 침 뱉는 소리를 적용했습니다. 근거리 난사는 맞은 적에게 분사 1회당 산성 화상 피해 5를 줍니다. Camera+ 최대 확대에서 시전자가 화면 밖에 있어도 화면에 걸친 촉수 액션을 표시합니다.
- **사목 무기와 연단낭** — 연단낭의 작업 탭에서 사목의 활과 단검을 제작합니다. 각 무기의 재료는 사목의 촉수 140개, 백교질 95개, 맥동조직 30개입니다. 연단낭의 내부 원료 가공과 제작 작업은 함께 진행할 수 있습니다. 활과 단검의 상호 변형은 한 무기를 다른 형태로 바꾸며 제작품의 품질을 유지합니다.

## 2026-11-14 변경사항

### 추가

- **사목의 촉수 2식** — 생체 아머 착용과 연동되며, 일제공격·촉수총난타·충돌 피해·집기와 투척을 지원합니다. 투척 사거리는 무게에 따라 24~32칸이며 건축물 직격 피해에 3배 배율을 적용합니다.
- **유란 생체 아머** — 방향별 착용 그래픽, 생체 애니메이션, 가스 헬멧과 백윤액 분비를 추가했습니다.
- **사목의 공생외투** — 뿌리내림과 공격·지원·공생 조율 모드, 긴급구조, 태동실, 카트리지 보급과 투여 능력, 최음침식가스를 추가했습니다. 연단낭 제작에는 사목의 촉수 180개, 백교질 120개, 맥동조직 60개가 필요합니다.
- **유란 촉수 의상과 사목암살자 후드** — 후드는 머리 슬롯 장비로 따로 착용합니다. 정면 후드 안쪽에 얼굴과 앞머리가 비치는 그늘 효과를 추가했습니다. 방향별 위치·배율·회전각·겹침 순서를 조절하고 종족별 기본값으로 저장할 수 있습니다.

### 수정

- 유란의 암살·제압에는 기존 전용 몸통·다리 자세와 동·서 각도 조정을 복원했습니다. 다른 종족의 암살·제압과 모든 종족의 완전제압 착취에는 착용자의 현재 몸체와 의상을 사용합니다. 목장식의 실제 위치를 기준으로 케이프 촉수 6가닥을 그리도록 수정했습니다.
- 랫킨 네 방향과 드라고니안 동·서 방향에 의상 기본값을 추가했습니다. 드라고니안 동쪽은 외부인들1의 서쪽 저장값에서 파츠를 대응시켜 좌우 위치와 회전각을 반전했습니다.
- 사목의 벽 연결 텍스처, 백윤액 사격·사출, 사목의 채찍과 장비 생성 관련 처리를 수정했습니다.

### 미완성

- **촉수 의상 액션 연출** — 타종족에서 촉수가 얼굴과 목장식을 가로지르는 현상을 공통 렌더링 경로에서 수정했습니다. 최신 보정의 인게임 확인과 종족별 후드·의상 핏 검증이 남아 있습니다. 완전제압 반복음 설정 경고도 남아 있습니다.
- **공생외투 연출과 호환성** — 태동실 벽·백윤액 애니메이션, 방향별 의상·투구 핏, 추가 종족 및 밸런스 검증이 남아 있습니다.
- **시연맵** — 외부인들1 로드 중 샌드백 위치 저장 데이터 경고가 확인됐습니다. 시연맵과 세이브는 배포 대상에서 제외합니다.
